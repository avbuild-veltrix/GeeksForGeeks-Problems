# Addition of Two Numbers

![Difficulty](https://img.shields.io/badge/Difficulty-Basic-red)

## Problem

Given two numbers  **a** and  **b,** return the sum of a and b.

 **Examples:** 

```
Input: a = 1, b = 2
Output: 3
Explanation: Addition of 1 and 2 is 3.
```

```
Input: a = 10, b = 20
Output: 30
Explanation: Addition of 10 and 20 is 30.
```
